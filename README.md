## What I Learned

1.  **Box Model:** Deep understanding of content, padding, border, margin and how `box-sizing: border-box` simplifies layout.
2.  **Responsive Layout:** Building flexible layouts using Flexbox and CSS Grid with media queries.
3.  **Git Team Workflow:** The full cycle - `feature/precious` branch -> commit `feat: add card` -> push -> Pull Request -> Review -> Approve -> Merge -> Delete branch.
4.  **Branch Protection:** Why we protect `main` - to prevent direct pushes and force code review for quality.
5.  **Collaboration:** How to avoid merge conflicts by always pulling latest `main` before creating a new feature branch.
6.  **Documentation:** Writing professional README and using Conventional Commits.
